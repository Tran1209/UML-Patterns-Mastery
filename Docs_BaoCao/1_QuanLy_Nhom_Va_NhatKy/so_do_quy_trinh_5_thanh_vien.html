4 Nguyên Tắc Vàng Khi Làm Việc Cùng Antigravity

1. Antigravity là Local

AI chỉ đọc và viết file trong máy tính của bạn. Không bao giờ tự ý đẩy lên GitHub nếu bạn chưa bấm lệnh.

2. Test trước khi Push

Viết xong code bằng AI, luôn bấm phím [1] để game tự biên dịch và chạy thử xem có lỗi hay không.

3. Phím [3] là Lưu Trữ

Hết buổi làm việc hoặc xong một tính năng, bấm [3] để gửi code lên nhánh cá nhân làm mốc an toàn.

4. Phím [4] khi cần code mới

Khi Lead Architect thông báo đã gộp tính năng mới vào main, các bạn bấm [4] để máy mình lập tức có code mới nhất.
