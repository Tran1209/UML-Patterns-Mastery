# Implementing Domain-Driven Design - Vaughn Vernon
## Không gian làm việc Trích xuất Lý thuyết (10 Đợt)

Thư mục này dành riêng cho việc lưu trữ các đợt trích xuất chi tiết theo Master Prompt từ tác phẩm đầu ngành:
**"Implementing Domain-Driven Design" (IDDD)** - Vaughn Vernon.

---

### 📋 Lộ trình 10 Đợt Trích Xuất (Lưu vào thư mục `10_Runs/`)
1. **Đợt 01**: Khởi động DDD, Tại sao cần DDD, Ngôn ngữ phổ quát (Ubiquitous Language) và Bounded Context.
2. **Đợt 02**: Subdomains & Bounded Contexts: Core Domain, Supporting Domain, Generic Subdomain.
3. **Đợt 03**: Bản đồ Ngữ cảnh (Context Mapping): Shared Kernel, Customer-Supplier, Conformist, Anti-Corruption Layer (ACL).
4. **Đợt 04**: Kiến trúc trong DDD: Hexagonal (Ports & Adapters), Onion, Clean Architecture, CQRS, Event-Driven.
5. **Đợt 05**: Entities: Định danh duy nhất (Unique Identity), Vòng đời thực thể, Tính khả biến và Bất biến.
6. **Đợt 06**: Value Objects: Đặc tính bất biến (Immutability), So sánh theo giá trị, Thiết kế Side-Effect-Free Functions.
7. **Đợt 07**: Domain Services: Khi nào dùng Service, Phân biệt Domain Service vs Application Service.
8. **Đợt 08**: Domain Events: Thiết kế, Đăng ký (Subscribe), Phát sự kiện (Publish) và Xử lý Bất đồng bộ.
9. **Đợt 09**: Aggregates: Ranh giới giao dịch (Transactional Consistency Boundary), Quy tắc thiết kế 4 nguyên tắc Aggregate.
10. **Đợt 10**: Repositories, Event Sourcing & Tổng hợp `FULL_Vaughn_Vernon_IDDD.md`.
