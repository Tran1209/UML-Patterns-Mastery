# Multiplayer Game Programming - Joshua Glazer & Sanjay Madhav
## Không gian làm việc Trích xuất Lý thuyết (10 Đợt)

Thư mục này dành riêng cho việc lưu trữ các đợt trích xuất chi tiết theo Master Prompt từ giáo trình:
**"Multiplayer Game Programming: Architecting Networked Games"** - Joshua Glazer & Sanjay Madhav.

---

### 📋 Lộ trình 10 Đợt Trích Xuất (Lưu vào thư mục `10_Runs/`)
1. **Đợt 01**: Tổng quan Mạng Game, Mô hình Client-Server vs Peer-to-Peer, Kiến trúc Mạng Đa tầng.
2. **Đợt 02**: Giao thức Tầng Vận chuyển: UDP vs TCP, Non-blocking Sockets, Socket Options trong Game.
3. **Đợt 03**: Serialization & Bit Streams, Đóng gói Dữ liệu Nhị phân, Tối ưu Kích thước Gói tin.
4. **Đợt 04**: Giao thức Tin cậy trên nền UDP (Reliability over UDP), ACK/NACK, Packet Sequence.
5. **Đợt 05**: Object Replication & Đồng bộ Thực thể (World State Replication, Dirty Bits).
6. **Đợt 06**: Khử Độ trễ (Latency Mitigation): Dead Reckoning, Interpolation, Extrapolation.
7. **Đợt 07**: Client-Side Prediction và Server Reconciliation trong chuyển động nhân vật.
8. **Đợt 08**: Lag Compensation (Rewind Time / History Buffers) cho cơ chế bắn đạn và va chạm.
9. **Đợt 09**: Bảo mật Mạng Game (Anti-Cheat, Mã hóa, Xác thực, Chống DDoS và Giả mạo Gói tin).
10. **Đợt 10**: Scalability, Dedicated Server Hosting, Matchmaking và Tổng hợp `FULL_Glazer_Madhav_Netcode.md`.
