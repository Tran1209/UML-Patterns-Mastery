# Patterns of Enterprise Application Architecture - Martin Fowler
## Không gian làm việc Trích xuất Lý thuyết (10 Đợt)

Thư mục này dành riêng cho việc lưu trữ các đợt trích xuất chi tiết theo Master Prompt từ tác phẩm kinh điển:
**"Patterns of Enterprise Application Architecture" (PoEAA)** - Martin Fowler.

---

### 📋 Lộ trình 10 Đợt Trích Xuất (Lưu vào thư mục `10_Runs/`)
1. **Đợt 01**: Tổng quan Kiến trúc Phần mềm Doanh nghiệp, Phân tầng (Layering) và Khái niệm Tách rời Trách nhiệm.
2. **Đợt 02**: Domain Logic Patterns: Transaction Script, Domain Model, Table Module, Service Layer.
3. **Đợt 03**: Data Source Architectural Patterns: Table Data Gateway, Row Data Gateway, Active Record, Data Mapper.
4. **Đợt 04**: Object-Relational Behavioral Patterns: Unit of Work, Identity Map, Lazy Load (Virtual Proxy, Value Holder).
5. **Đợt 05**: Object-Relational Structural Patterns: Identity Field, Foreign Key Mapping, Association Table Mapping.
6. **Đợt 06**: Object-Relational Structural Patterns (tiếp): Inheritance Mappers (Single Table, Class Table, Concrete Table).
7. **Đợt 07**: Web Presentation Patterns: Model View Controller (MVC), Page Controller, Front Controller, Template View.
8. **Đợt 08**: Distribution Patterns: Remote Facade, Data Transfer Object (DTO), Session State Management.
9. **Đợt 09**: Offline Concurrency Patterns: Optimistic Offline Lock, Pessimistic Offline Lock, Coarse-Grained Lock.
10. **Đợt 10**: Base Patterns (Registry, Value Object, Money, Gateway, Plugin, Service Stub) & Tổng hợp `FULL_Martin_Fowler_PoEAA.md`.
